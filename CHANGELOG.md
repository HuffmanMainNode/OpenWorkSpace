# Changelog

## [0.1.0] - Unreleased

### Added
- Initial Python package and CLI.
- JSON Schema 2020-12 capability manifest contract and validator.
- Explicit default-deny permission decision primitive.
- Local hash-linked JSONL evidence journal and verifier.
- Unit tests and continuous integration workflow.
- Initial security, contribution, governance, and architecture documentation.

### Limitations
- No third-party plugin execution.
- No OS-level sandbox, credential vault, or network firewall.
- Evidence hash chain is tamper-evident, not tamper-proof against a privileged local administrator.
