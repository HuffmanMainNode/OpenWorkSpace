# Community Resource Collection

Third-party projects are independently authored. They must be visibly distinguished from first-party work.

The initial community catalog is empty by design. New entries require public-source verification, attribution, license review, maintenance assessment, dependency review, security review, compatibility assessment, pinned source revision, and recorded limitations.

Public availability is not a license to copy, package, or redistribute. Reference-only links may be appropriate when redistribution terms are unclear. Discovery and catalog inclusion never authorize execution.
