# Optional Resource Packs

Packs group catalog references by user need. They are optional collections, not monolithic bundles and not automatic installation plans.

Proposed pack families:
- Developer foundations
- AI and agent systems
- Trust and defensive security
- Intelligence and research
- Interoperability and testing
- Storage and preservation

A pack record should pin each resource to a reviewed catalog ID and source revision, state its purpose, list dependencies, identify license constraints, and explain which items are reference-only versus downloadable. Users select and install resources individually. No pack may enable code execution by default.
