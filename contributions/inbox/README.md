# Contribution inbox

Submit one metadata-first proposal per directory:

`contributions/inbox/<contribution-id>/`

Required files:
- `contribution.json`: schema-valid proposal manifest.
- `README.md`: purpose, intended users, setup performed by a human, supported platforms, limitations, and upstream documentation.
- `REVIEW-NOTES.md`: optional submitter-provided verification notes. Maintainers add their own review evidence during triage.

Do not include source archives, binaries, executables, secrets, private data, or vendored dependencies. This directory is an untrusted proposal queue. Nothing placed here is installed, executed, or automatically promoted.
