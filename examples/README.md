# Examples

The files in this directory are declarative examples and synthetic fixtures. They are not plugins and are not executable.

- `hello-capability.json`: a capability manifest for validation and local registration.
- `contracts/identity.json`: example local user identity metadata.
- `contracts/service-identity.json`: example local service identity metadata.
- `contracts/task.json`: task lifecycle fixture owned by the example user.
- `contracts/message.json`: local message envelope from the example user to the example service.
- `contracts/`: other schema conformance fixtures.

See the [getting started guide](../documentation/getting-started/README.md) for commands. A valid fixture is not a credential, authorization, or executable package.
